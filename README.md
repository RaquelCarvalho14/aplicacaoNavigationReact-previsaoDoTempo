## Instruções de execução

> ⚠️ Para Windows, é necessário rodar antes:
> ```
> Set-ExecutionPolicy Unrestricted -Scope Process
> ```

1. Instale as dependências do projeto:

   ```
   npm install
   ```

2. Inicie o projeto:

   ```
   npx expo start
   ```
